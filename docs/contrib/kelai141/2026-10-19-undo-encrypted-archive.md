# 加密快照导入导出的明文落盘修复

关联 #428 第 8、9 项。原实现先写明文 ZIP，再加密覆盖；导入解密也写固定临时路径。中断可能留下完整明文。

ZIP 新增内存构造与解析入口，保留既有文件 API、ZIP 和密文格式。加密导出只把密文字节写入同目录独占临时文件，sync 后 rename 发布；失败保留原目标。加密导入直接在内存解析解密结果。导出名增加随机后缀，避免同秒任务互相覆盖。

验证：node --test scripts/source-build/undo-archive-safety.test.mjs，3 项通过。覆盖旧 ZIP API 兼容、并发发布完整性、发布故障旧字节保留、加密写入字节观测、导入内容与错误密码。未做设备验证：当前 ADB 无连接设备。不得据此声明 APK 三层验收完成。

内存构造会额外持有 ZIP Buffer；原读入和加密路径本已全量驻留。流式归档不在本次改动范围。用户旧快照、密码格式与目录不迁移。
